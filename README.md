# 국립공원 데이터 한눈에

국립공원공단 직원이 공식 공개데이터를 조회하고 비교하는 정적 웹앱입니다. 2026년 10월 5일 실제 API로 5종 45,706행을 수집했습니다. DB와 사용자 파일 업로드는 사용하지 않습니다. 비밀키는 수집 작업에만 사용하며 배포 폴더에는 포함하지 않습니다.

## 현재 사용 가능한 기능

- 24개 공원 선택과 분야별 데이터 조회
- 로드킬·산사태의 공원별 공개 기록 비교와 연도 그래프
- 설악산 탐방지역별 계수 기록 추이
- 로드킬·산사태·경관자원 좌표 지도와 원본 목록
- 출처·관측기간·자료 버전·원본 수정일·수집 성공일 표시
- 현재 조건 전체 표의 CSV 저장과 표 복사
- 출처와 조회 조건을 포함한 그래프 PNG 저장
- 모바일·PC용 반응형 레이아웃

건축물과 경관자료는 공원 귀속을 추정하지 않고 전국 목록으로 제공합니다. 건축물 X·Y 좌표는 좌표계 확인 전 지도에서 제외합니다. 탐방객은 여러 지점을 합산하거나 지점명을 임의로 통합하지 않습니다. 원본에서 동일 내용의 행이 있어도 조사단위가 확인되기 전 삭제하지 않습니다. 지도 PNG는 지원하지 않습니다.

## 로컬 화면 열기

프로젝트 폴더에서 `node serve.mjs`를 실행하고 일반 웹브라우저에서 http://127.0.0.1:4173 을 엽니다. 서버가 이미 실행 중이면 바로 주소를 열면 됩니다. HTML 파일을 더블클릭하면 데이터 조회가 제한될 수 있으므로 웹서버를 사용하세요. 별도 패키지 설치가 필요 없습니다.

## 데이터 갱신

1. `.env.local`의 인증키 설정을 유지합니다. 공통 키는 DATA_GO_KR_SERVICE_KEY, 개별 키는 기존 5개 변수로 설정할 수 있습니다.
2. `node collect-data.mjs`로 공식 API 전체 페이지를 수집합니다.
3. `node build-data.mjs`로 검증된 정적 JSON을 생성합니다.
4. `node --test tests/*.test.mjs`로 실제 원본과 집계 일치를 검증합니다.

수집 실패 또는 페이지 불일치는 성공으로 처리하지 않습니다. 각 원본은 전체 수신 행수 검증 후 저장하며 실패하면 마지막 성공 파일을 보존합니다. 원본과 중간 결과는 무시된 work 폴더에 저장합니다. site 폴더만 배포합니다.

## 구조와 기술 선택

브라우저의 표준 JavaScript 모듈, CSS, SVG 그래프와 OpenStreetMap 배경 타일을 사용합니다. 지도는 위경도의 Web Mercator 투영이며 외부 지오코딩을 하지 않습니다. 배경지도에는 OSM 출처를 표시하고 대량 다운로드나 오프라인 타일 저장은 하지 않습니다. 외부 폰트·차트 라이브러리·지도 API 키는 필요하지 않습니다.

초기 설계의 React·Vite 대신 의존성 설치가 필요 없는 정적 구현을 채택했습니다. 데이터량과 기능 범위를 감안한 유지관리 비용 절감 선택이며 Vercel 정적 배포에 맞춰 site 폴더를 준비했습니다. 차후 기능 확장이나 성능 문제가 확인되면 프레임워크 도입을 검토합니다.

## GitHub와 Vercel 연결 전

사용자가 GitHub의 빈 저장소를 직접 생성하고 저장소 URL을 알려주면 로컬 소스를 연결합니다. .env.local과 work 원본·검증보고서는 저장소에서 제외되며 공개 수집 결과만 site/data에 포함됩니다. Vercel 프로젝트 생성·연결은 그 이후에 사용자에게 요청합니다. 아직 원격 저장소·Vercel 프로젝트를 생성하거나 배포하지 않았습니다.

Vercel 설정은 `vercel.json`에 있으며 정적 배포 출력은 site입니다. 배포에서는 API를 호출하지 않습니다. 계정별 업무 이용 조건, Git 연결 권한, 배포 설정은 실제 프로젝트 생성 후 확인합니다.

GitHub Actions의 refresh 작업은 수동 실행으로만 준비했습니다. 공통 인증키 Secret을 설정하고 실제 실행 및 배포 연동을 검증한 뒤 예약 실행을 활성화합니다. 지금은 자동 갱신이 운영 중이라고 표시하지 않습니다. 인증키가 포함된 환경변수 파일과 URL·예외 내용을 출력하지 않습니다.

## 검증 범위와 남은 확인

원본 전체 수신 행수, 공원 ID, 날짜·연도 검증, 도분초 좌표 변환, 원본행 보존, 공원별·지점별 집계 일치, CSV 이스케이프와 결측·0 구분을 자동 검증했습니다. 로컬 서버의 HTML·JSON·모듈 반환과 비밀 설정 파일 접근 차단도 확인했습니다.

현재 환경의 내장 브라우저에서 로컬 주소 접속이 차단되어 실제 화면의 시각적 검사, 모바일 조작, PNG 다운로드와 클립보드 동작, 배경지도 타일 로딩은 아직 검증하지 못했습니다. 배포 전 사용자 PC 브라우저에서 확인해야 합니다. 코드 구현만으로 이 확인이 완료됐다고 주장하지 않습니다.

## 데이터 이용 시 주의할 해석

로드킬과 산사태의 수치는 공개 기록 수이며 실제 사고 총수·위험도·관리 성과를 뜻하지 않습니다. 기록이 없는 공원과 기간을 0으로 채우지 않습니다. 설악산 탐방객 자료의 2026년 수치는 3월까지의 부분 기간입니다. 건축물 시공연도는 현황 기준일이 아니며 두 자리 연도나 누락을 보정하지 않습니다. 경관자료에는 조사 기준일이 없어 기준일 미확인으로 표시합니다.
